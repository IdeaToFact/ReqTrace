## 3. Mandatory Human-in-the-Loop Verification (Engine, Heuristic & AI Limitations)

ReqTrace combines deterministic tag parsing, AST static code inspection, character-level fuzzy windowing (`rapidfuzz`), automated test result aggregation (JUnit XML / PyTest), and optional local semantic or LLM extensions (`reqtrace.extensions`).

- **Potential for Errors, Omissions & False Positives**: Static parsers, regex patterns, fuzzy confidence scores, and optional semantic/LLM rationalizations may misparse non-standard ReqIF/DOCX schemas, omit unannotated test methods, fail to detect dynamic runtime test behavior, or produce false-positive candidate matches or inaccurate AI rationalizations.
- **Self-Reported Review & Waiver Records**: Recording an `approved`, `rejected`, or `waived_analysis` entry in `.reqtrace/reviews.jsonl` (via CLI or `reqtrace ui`) stores only the user-entered identity string and justification. Community Edition performs **no** cryptographic PKI identity verification, qualified electronic signing (eIDAS / FDA 21 CFR Part 11), or independent validation of waiver adequacy. Similarly, SHA-256 hashes computed by `ExportManager` verify file integrity only and do not constitute legal non-repudiation.
- **Mandatory Engineering Review**: Every trace link, candidate suggestion, waiver, unverified requirement flag, orphan report, and exported deliverable generated by ReqTrace **must be independently reviewed and verified by a qualified systems engineer or verification lead** prior to design freeze, physical testing, flight release, medical device submission, or production deployment.
